# Think Like a Lawyer — course files

- Roadmap page (all 56 lessons): https://claude.ai/artifact/Kq1tfDtiPMKTJ8UArEA5Li
- Lesson pages are listed below. Each page has a Listen button that plays a recording of the lesson.
- `tools/tts_setup.sh` and `tools/make_audio.py` make that recording offline (Kokoro voice, from npm and PyPI).
- The roadmap page is pinned in the Claude sidebar and lists every delivered lesson. `tools/build_roadmap.py` rebuilds it.
- `SYLLABUS.md` is the plan. `DAILY_PROMPT.md` is what the scheduled task follows each evening.
- `template/lesson.html` is the page every lesson is built from. `lessons/` holds each lesson as `.md` and `.html`.
